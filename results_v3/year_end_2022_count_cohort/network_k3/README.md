# Historical single-reference network validation

These are the earlier K3 seed492-only results (999 permutations, a twelve-test
Holm family). They are retained for provenance and exact-edge-count checks.

The current manuscript uses `../network_comparison/`: shared samples for seven
annual solutions, 9,999 common permutations, and one 84-test Holm family.
Do not mix the old p-values with the expanded comparison's correction.
