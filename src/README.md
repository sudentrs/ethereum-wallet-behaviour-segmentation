# Source Code

The scripts in this folder are organized by analysis stage.

This is a curated copy of the final project pipeline, not a complete dump of every exploratory script in the original workspace.

Read `../docs/PIPELINE.md` before running scripts.

Many scripts were originally written during active exploration and may still assume local input paths.

Before rerunning:

1. Place required data under `data/` or update script paths.
2. Install dependencies from `requirements.txt`.
3. Run scripts stage by stage rather than all at once.
